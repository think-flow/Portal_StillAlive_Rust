单线程 架构重构

Portal Still Alive Rust 终端动画播放器：从 thread::scope + mpsc 的多线程模型， 到基于状态机 + 协作式 tick 的单线程事件循环。

After

单线程事件循环 + 三状态机

重构后，stage.rs 是编排器，声明三个子模块作为状态机，在 10ms 主循环中依次 tick。

src/ ├── stage.rs ← 编排器（Stage + run() 主循环） ├── stage/ │ ├── art.rs ← ArtState 状态机 │ ├── credit.rs ← CreditState 状态机 │ └── lyric.rs ← LyricTyping + clear_lyrics ├── data/... ├── lib.rs ← typed! 宏 └── main.rs ← 入口 + 退出等待
// 三个状态机子模块 mod art; mod credit; mod lyric; pub fn run(&self) -> Result<()> { let mut typing_state: Option<lyric::LyricTyping> = None; let mut art_state: Option<art::ArtState> = None; let mut credit_state: Option<credit::CreditState> = None; loop { // ─── 10ms 主循环 ─── // 1. 空闲时触发新事件 if typing_state.is_none() && art_state.is_none() { match lyrics[lyric_idx].mode { 0|1 => typing_state = Some(lyric::LyricTyping::new(...)); 2 => art_state = Some(art::ArtState::new(...)); 3 => lyric::clear_lyrics(self); 4 => player::play(...); 5 => credit_state = Some(CreditState::new()); } } // 2. 依次 tick 所有活跃状态机 if let Some(ref mut ts) = typing_state { ts.tick(self); } if let Some(ref mut as_) = art_state { as_.tick(self); } if let Some(ref mut cs) = credit_state { while cs.is_ready() { cs.tick(self); } } // 3. 游标刷新 + 睡眠 thread::sleep(Duration::from_millis(10)); } }

LyricTyping — 歌词打字

在 stage/lyric.rs 中。每次 tick() 检查 elapsed >= char_idx × interval，条件满足时输出一个字符。

pub struct LyricTyping { pub text: &'static str, pub char_idx: usize, pub cursor_x: i32, pub cursor_y: i32, interval: f64, new_line: bool, started_at: Instant, } impl LyricTyping { pub fn tick(&mut self, stage: &Stage) { let elapsed = self.started_at.elapsed().as_secs_f64(); while self.char_idx < self.text.len() { if elapsed < self.char_idx as f64 * self.interval { return; // 时间未到，下次 tick 再试 } // 输出一个字符 stage.move_to(self.cursor_x, self.cursor_y); typed("{}", &self.text[self.char_idx..]); self.char_idx += 1; } } }

ArtState — ASCII art

在 stage/art.rs 中。每 tick() 输出一行 art，速率由主循环 10ms 间隔保证。不再阻塞 200ms。

pub struct ArtState { pub ch: i32, pub dy: i32, } impl ArtState { pub fn tick(&mut self, stage: &Stage) { if self.dy >= stage.ascii_art_height { return; } let art = data::ARTS[self.ch as usize]; stage.move_to(stage.ascii_art_x, stage.ascii_art_y + self.dy); typed("{}", art[self.dy as usize]); self.dy += 1; } }

CreditState — 职员表滚动

在 stage/credit.rs 中。is_ready() 检查当前是否该显示下一个字符，主循环用 while 一次性消化积压。 行文本通过字节偏移量从 CREDITS 直接切片获得，无需额外分配。

pub struct CreditState { j: usize, line_idx: usize, char_pos: usize, started_at: Instant, line_starts: Vec<u32>, // 每行在 CREDITS 中的字节偏移 } impl CreditState { pub fn is_ready(&self) -> bool { !self.is_done() && self.started_at.elapsed().as_secs_f64() >= 174.0 * self.j as f64 / CREDITS.len() as f64 } pub fn tick(&mut self, stage: &Stage) { let ch = &CREDITS[self.j..]; self.j += 1; if ch == "\n" { self.line_starts.push(self.j as u32); // 底部对齐重绘所有可见行 // line_text(i) = &CREDITS[starts[i]..starts[i+1]-1] redraw_visible(...); } else { // 在最后一行输出一个字符 stage.move_to(pos_x + char_pos, height + 1); typed("{}", ch); } } }
